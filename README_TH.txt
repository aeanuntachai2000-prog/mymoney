MyMoney - ต้นแบบแอปรายรับรายจ่าย

วิธีเปิด:
1) เปิด VS Code
2) เลือก File > Open Folder แล้วเลือกโฟลเดอร์ MyMoney
3) ติดตั้ง Extension ชื่อ Live Server (โดย Ritwick Dey)
4) คลิกขวา index.html แล้วเลือก Open with Live Server
5) ทดลองเพิ่มรายรับ รายจ่าย และโอนเงิน

ความสามารถในต้นแบบ:
- บันทึกรายรับ รายจ่าย และโอนเงิน
- ยอดรวมและยอดรายรับ/รายจ่ายเดือนปัจจุบัน
- กรองและลบรายการ
- ส่งออก CSV สำรองข้อมูล
- หน้าจอปรับตามขนาดมือถือ

ข้อจำกัด:
- เก็บข้อมูลในเบราว์เซอร์ที่ใช้งานด้วย localStorage; ไม่ซิงก์ข้ามคอม/มือถือ
- ยังไม่มีระบบแก้ไขรายการเดิม จัดการบัญชี/หมวดหมู่ งบประมาณ และกราฟรายงาน
- อย่าล้างข้อมูลเบราว์เซอร์ก่อนส่งออก CSV สำรองข้อมูล
- เพื่อใช้บน iPhone ต้องเผยแพร่ผ่าน HTTPS แล้วเปิดด้วย Safari; Live Server บนคอมใช้ทดสอบบนคอมก่อน
